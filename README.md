# 🌐 Portfólio de Projetos

> Portfólio acadêmico desenvolvido por alunos do curso Técnico em Desenvolvimento de Sistemas da ETEC Cidade Tiradentes.

🔗 **Acesse o site:** https://nosso-portifolio.vercel.app/

## 📖 Sobre o projeto

Este projeto reúne trabalhos desenvolvidos durante o curso de Desenvolvimento de Sistemas, com o objetivo de apresentar os conhecimentos adquiridos pelos alunos por meio de páginas web temáticas.

O site funciona como um portfólio que reúne quatro projetos independentes: currículos, destinos turísticos, carros antigos e playlists musicais. Cada seção possui páginas próprias, com conteúdos, imagens e opções de navegação.

## ✨ Projetos disponíveis

### 1. 📄 Currículos

Seção dedicada à apresentação de currículos acadêmicos e profissionais dos alunos.

- Dados pessoais e informações de formação.
- Experiências profissionais.
- Cursos extracurriculares e habilidades.
- Objetivos profissionais.
- Navegação entre os currículos apresentados.

### 2. ✈️ Viagens

Projeto sobre destinos turísticos, com informações e sugestões de lugares para conhecer ao redor do mundo.

Destinos apresentados:

- 🇪🇸 Espanha — Madrid.
- 🇮🇹 Itália — Toscana.
- 🇺🇸 Estados Unidos — Califórnia.
- 🇯🇵 Japão — Shibuya.
- 🇫🇷 França — Paris.

Cada página apresenta descrições dos destinos, pontos turísticos, restaurantes, museus e links externos relacionados aos locais mencionados.

### 3. 🚘 Carros Antigos

Seção dedicada à história e às características de automóveis clássicos, especialmente modelos conhecidos pela indústria automobilística e pela cultura popular.

Modelos apresentados:

- Ford Mustang Shelby Eleanor 1967.
- Dodge Charger 1970.
- Chevrolet Opala 1976.
- Plymouth Superbird 1970.
- Chevrolet Impala 1967.
- Chevrolet Chevelle 1967.
- Ford Maverick 1974.
- Chrysler New Yorker 1970.

As páginas apresentam descrições dos veículos, informações históricas, características dos motores e imagens ilustrativas.

### 4. 🎵 Playlist

Projeto musical que reúne duas seleções de músicas de diferentes artistas e estilos.

Entre os artistas e grupos apresentados estão Avicii, Linkin Park, The Calling, The Script, Zach Bryan, Metallica, Green Day, Victor e Leo, Grupo Revelação e Imagine Dragons.

A seção organiza as músicas em páginas próprias, com imagens e opções de navegação.

## 🛠️ Tecnologias

O projeto é composto por páginas web estáticas em HTML, conforme indicado pelas páginas `.html` publicadas no site.

- **HTML5:** estruturação do conteúdo das páginas.
- **CSS3:** estilização visual, caso utilizada nos arquivos do projeto.
- **Vercel:** publicação e hospedagem do site.

*Observação: a confirmação das tecnologias de estilização e da configuração de hospedagem depende da inspeção dos arquivos-fonte e das configurações do repositório.*

## 🚀 Como executar o projeto

Para visualizar o portfólio, acesse o site publicado:

**https://nosso-portifolio.vercel.app/**

Para executar uma cópia local:

1. Clone o repositório do GitHub.
2. Abra a pasta do projeto no Visual Studio Code ou em outro editor.
3. Abra o arquivo HTML principal no navegador ou utilize a extensão Live Server do VS Code, se disponível.
4. Navegue pelas seções e páginas do projeto.

```bash
git clone URL_DO_REPOSITORIO
cd NOME_DO_REPOSITORIO
```

Substitua `URL_DO_REPOSITORIO` e `NOME_DO_REPOSITORIO` pelos valores correspondentes ao seu repositório.
